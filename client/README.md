# Cipher DesignLab

An AI-assisted Low-Level Design practice platform built for the CipherSchools Full Stack Development engineering assignment.

Cipher DesignLab helps learners move beyond simply reading LLD solutions.

Instead, learners:

1. Choose a design problem.
2. Create a structured design attempt.
3. Explain requirements and assumptions.
4. Model classes, interfaces and relationships.
5. Document trade-offs and edge cases.
6. Save their work as a draft.
7. Submit the design for asynchronous evaluation.
8. Receive evidence-backed rubric feedback.
9. Review previous attempts.
10. Retry the same problem and improve.

---

## Product Motivation

Low-Level Design practice has an unusual feedback problem.

A learner can design systems such as:

- Parking Lot
- Elevator System
- Vending Machine
- Notification Service

but there may be several valid architectures.

This means evaluation should not simply compare the learner against one reference solution.

Cipher DesignLab evaluates the quality of the learner's reasoning across a fixed rubric while grounding feedback in evidence from the submitted design.
